# Smart Banking Management System

A console-based banking management system built using Java, MySQL, and JDBC.

## Features

- User Registration
- User Login
- Account Management
- Check Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History

## Technologies Used

- Java
- MySQL
- JDBC

## Project Objective

This project is developed to practice Java, SQL, JDBC, and object-oriented programming concepts by building a simple banking management system.
